# TJTM EGG Ecosystem Roster

This directory is the standalone TJTM EGG roster. It is intentionally separate from `aisiservices/` and does not merge or imply ownership of other project registries.

- `index.html` — independent searchable roster website.
- `agents.json` — the EGG roster data source.

The current data is an initial transcription from the owner-provided conversation roster, not the complete long source list. Add or correct records in `agents.json`; do not infer missing GPT URLs. Source access labels are descriptive metadata only and do not change the actual visibility of GPTs. Human source authority and final editorial approval: TJ Morris.

If GitHub Pages serves the repository root, this roster is available at `/egg/`. The public front-page project link can be added after this standalone section is reviewed.
